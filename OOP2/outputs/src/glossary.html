When you seeIt means
static void Main() { … }The starting point. The program runs the lines inside it, top to bottom.
class Dog { … }A class: the blueprint for one kind of object. Everything between its { and } belongs to it.
public int age;A field: a value each Dog object stores. int = whole number, double = decimal number, string = text, bool = true/false.
public void Bark() { … }A method: named steps the object can do. void = it gives nothing back.
public int GetAge() { return age; }A method that gives a value back with return.
Dog d = new Dog();Builds one Dog object and keeps it in the variable d.
d.Bark();Runs Bark on that object. The dot means "of this object".
Console.WriteLine(x);Prints x, then moves to a new line. Console.Write(x) stays on the same line.
; and { }; ends one instruction. { } groups lines together.
// some textA comment. The computer ignores it.
