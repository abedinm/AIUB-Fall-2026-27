Ch 5: IT Infrastructure and Emerging Technologies

NOT FROM COURSE SLIDES - textbook (Laudon 18th ed.)

5.1 What IT infrastructure is

  • IT infrastructure = the shared technology resources (hardware, software, services) that are the platform for the firm's specific information systems.
  • Two views: a set of physical devices and software, and a set of firm-wide services (computing, telecom, data management, application software, facilities, IT management, standards, education, R&D services).

5.2 Five eras of IT infrastructure evolution

2. Personal computer1981IBM PC; Wintel (Windows + Intel); desktop productivity tools
3. Client/server1983Desktop clients request services from servers; two-tier and multitier (N-tier: web server + application server)
4. Enterprise computing1992Internet standards (TCP/IP) link different networks into one enterprise-wide infrastructure
5. Cloud and mobile computing2000Computing power, storage and software delivered over the Internet; smartphones and tablets
Memory hook: "My Personal Computer Eats Clouds" = Mainframe, PC, Client/server, Enterprise, Cloud/mobile.

  • Mobile digital platform: smartphones, tablets, wearables.
  • Consumerization of IT / BYOD: employees use their own devices for work.
  • Virtualization: one physical machine runs many virtual machines; fewer servers, lower cost.
  • Cloud computing (below), edge computing (process data near the source, e.g. IoT sensors).
  • Quantum computing: uses quantum physics to solve some problems far faster.
  • Green computing: reduce energy and environmental impact; multicore, power-saving processors.

  • TCO (total cost of ownership) = full cost of technology: hardware, software, installation, training, support, maintenance, infrastructure, downtime, space and energy. The purchase price is only a small part.

Ch 6: Databases, Business Intelligence and Blockchain

NOT FROM COURSE SLIDES - textbook (Laudon 18th ed.)

6.1 Data hierarchy

Bit → Byte → Field → Record → File → Database

  • Entity = a person, place, thing or event we keep data about (Student). Attribute = a characteristic of it (Student_ID, Name).

6.2 Problems of the traditional file environment

Each department keeps its own files and programs (data silos).

Memorize (5):
  1. Data redundancy and inconsistency - same data stored in many places, values do not match.
  2. Program-data dependence - changing the data format breaks the programs.
  3. Lack of flexibility - new or ad hoc reports are slow and costly.
  4. Poor security - little control over who sees the data.
  5. Lack of data sharing and availability - data locked in separate files.

6.3 The database approach

  • Database = a collection of data organized to serve many applications efficiently by centralizing the data and controlling redundancy.
  • DBMS (database management system) = software that lets a firm centralize data, manage it and give access to it (Oracle, SQL Server, MySQL, Access).
  • DBMS separates the logical view (how users see data) from the physical view (how it is stored).
  • Capabilities: data definition, data dictionary, data manipulation language (SQL: SELECT ... FROM ... WHERE).

6.4 Relational databases

  • Data in tables (relations): rows = records (tuples), columns = fields (attributes).
  • Primary key = field that uniquely identifies each record (Student_ID). Foreign key = a primary key of another table used to link tables.
  • Three operations: select (rows), project (columns), join (combine tables).
  • Normalization = turning complex groupings of data into small, stable tables to cut redundancy.
  • Entity-relationship diagram (ERD) = drawing of entities and relationships (one-to-one, one-to-many, many-to-many). Referential integrity = rules that keep links between tables consistent.
  • Also: NoSQL (non-relational) databases for big, unstructured data; cloud databases; distributed databases.

6.6 Blockchain

  • Blockchain = a distributed ledger: a chain of digital blocks of transactions shared across a network of computers (nodes), not one central server.
  • Each block is linked to the previous one by a cryptographic hash; changing one block breaks the chain, so records cannot be altered.
How it works (6 steps):
  1. A transaction is requested.
  2. It is broadcast to a peer-to-peer network of computers (nodes).
  3. The nodes validate it (consensus).
  4. It is combined with other transactions into a new block.
  5. The block is added to the chain, permanently.
  6. The transaction is complete and visible to all permitted parties.
  • Benefits: security, transparency, no single point of control, lower transaction costs. Uses: supply chain tracking, payments, contracts (smart contracts = code that runs when conditions are met), records.
  • Limits: energy use, speed, regulation.

Ch 7: Telecommunications, the Internet and Wireless Technology

NOT FROM COURSE SLIDES - textbook (Laudon 18th ed.)

7.1 Networks: parts and key technologies

  • Simple network: client and server computers, network interface cards (NIC), a connection medium, network operating system (NOS), switches and routers.
  • Client/server computing: clients request, servers provide.
  • Packet switching: a message is broken into small packets that travel by different paths and are reassembled at the destination. Efficient use of the network.
  • TCP/IP = the Internet's protocol suite. TCP handles moving data reliably between computers; IP handles addressing and delivering packets. Four layers: application, transport, Internet, network interface.
  • Protocol = set of rules for how computers communicate.
  • Signals: analog (continuous wave) vs digital (0s and 1s); a modem converts between them.

7.2 Types of networks and media

9.1 Supply chain management (slides 4-14)

  • SCM = close linkage and coordination of buying, making and moving a product. Integrates supplier, manufacturer, distributor and customer logistics.
  • Shares: orders, production, inventory levels, deliveries. Goal: right amount to the destination in the least time at the lowest cost.
  • Upstream = suppliers (primary) and their suppliers (secondary). Downstream = distributing and delivering to final customers. Reverse logistics = returns flowing back. Internal supply chain = turning materials into products inside the firm.
  • Inefficiencies can waste up to 25% of operating costs: parts shortages, idle plant capacity, excess finished goods. Cause: inaccurate or late information; uncertain demand, late shipments, defective parts, breakdowns.

9.2 Enterprise systems / ERP (slides 15-31)

  • Enterprise system (ERP) = integrated software modules + a central database shared by many processes and functions (Figure 9-1).
  • Modules: manufacturing/production, finance and accounting, HR, sales and marketing (CRM), supply chain and vendor management, corporate services.
  • Enterprise software is built on thousands of predefined best-practice business processes. To implement: select functions, map business processes to the software's processes, use configuration tables to customize.
  • ERP is structured in three layers (slide 24). Examples: SAP, Oracle, Microsoft, Sage, Odoo; tiers from enterprise (Tier 1) down to entry level (Tier 4).
  • Benefits: security and compliance, productivity, streamlined processes, growth, competition, mobility, saves money, integrated information, collaboration, customer service, forecasting and reporting.

L2. Explain the types of information systems by management level

  • Intro: different levels and interests need different systems; no single system serves all (Laudon Ch 2).
  • TPS (operational level): performs and records daily routine transactions; structured, predefined tasks. Inputs: transactions. Outputs: detailed reports, paychecks. Example: payroll, supermarket checkout. TPS is the main source of data for other systems; if it fails, the business stops.
  • MIS (middle management): summarizes TPS data into routine reports to monitor and control the business; questions specified in advance; little analysis. Example: monthly sales vs target report.
  • DSS (middle management): supports non-routine, unique, rapidly changing decisions; combines internal and external data with analytical models; "what-if". Example: voyage-estimating DSS for shipping bids.
  • ESS (senior management): non-routine decisions needing judgment and insight; uses summarized MIS/DSS data plus external data (competitors, tax laws); portal or BI dashboard. Example: Sabre airline dashboards.
  • Relationship: data flows upward: TPS → MIS/DSS → ESS. MIS, DSS and ESS are business intelligence systems. Firms now replace separate functional systems with integrated enterprise applications.

Short answers (5-line model answers)

S1. Distinguish data and information with an example.

Data are streams of raw facts, such as each checkout's "331 Brite Dish Soap 1.29". Information is data shaped into a meaningful, useful form, such as "Brite Dish Soap sold 7,156 units in the Northwest, YTD $9,231.24". An information system turns data into information through input, processing and output. Feedback lets managers correct the input. Managers decide with information, not raw data.

S2. Explain the three dimensions of information systems.

An IS is more than computers. Organizations: the hierarchy, business functions and culture the system serves. Management: managers make sense of situations, decide and form action plans, using the system's information. Technology: hardware, software, data management and networking technology, plus the IT infrastructure. All three must fit for the system to solve business problems.

S3. How is a DSS different from an MIS?

Both serve middle management. An MIS gives routine summary reports from TPS data for questions specified in advance, with little analysis. A DSS supports non-routine, rapidly changing decisions with no predefined procedure. It combines internal and external data with analytical models for "what-if" analysis. Example: MIS = monthly sales vs target; DSS = voyage-estimating bids.

S4. Value chain vs value web.

The value chain sees one firm as primary activities (inbound logistics, operations, outbound logistics, sales and marketing, service) and support activities (infrastructure, HR, technology, procurement). IS have most strategic impact where they add most value. A value web is a collection of independent firms that use IT to coordinate their value chains to serve a market collectively. It is more flexible and customer-driven than one linear chain.

S5. What is cloud computing? Explain IaaS, PaaS and SaaS.

Cloud computing provides processing, storage, software and services as a shared pool of resources over the Internet, paid by use. IaaS rents raw computing and storage (AWS). PaaS rents a platform to build and run your own applications (Azure). SaaS rents finished software online (Microsoft 365, Salesforce). Clouds can be public, private or hybrid.

S6. How does blockchain work?

A blockchain is a distributed ledger shared by many computers (nodes). A requested transaction is broadcast to the network, validated by the nodes and grouped with others into a block. The block is linked by a hash to the previous block and added to the chain permanently. Because every node holds a copy and blocks are linked, records cannot be altered. Uses: supply chains, payments, smart contracts.
